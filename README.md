# VIDARNET

*Deterministic systems. Observable intelligence. Verifiable workflows.*

## About VidarNet

VidarNet is an experimental engineering project exploring the integration of intelligent agents, deterministic systems and automation.

Our first public application focuses on MetaTrader 5 observability, reconciliation, risk metrics and reproducible testing.

Our research interests include:

- Intelligent agents and automation.
- Deterministic risk systems.
- Trading infrastructure and observability.
- Reproducible research.
- Human-supervised autonomous systems.

These are research directions, not claims of validated autonomous trading capability.

## Current Projects

### [Vidar MT5 Monitor](https://github.com/h377ll/vidar-mt5-monitor)

An experimental MT5 observation and reconciliation project with deterministic calculations, explicit data-quality states and synthetic validation. The public code includes demo observer sources, reconciliation and metrics components, test journals and an offline management simulator.

**Current version: `v0.1.0-dev`.** No order executor is included. Synthetic tests do not establish readiness for real accounts, validated autonomous execution or profitability.

## Engineering Principles

- **Deterministic calculations for critical operations:** critical calculations belong in inspectable code, not model inference.
- **Explicit data provenance:** distinguish known, estimated, unknown and unverifiable observations.
- **Auditable decisions:** retain inputs, assumptions and evidence for review.
- **Fail-safe behaviour:** incomplete evidence must not silently become permission to act.
- **Reproducible validation:** publish synthetic fixtures, test procedures and clearly bounded results.
- **Clear separation between observation and execution:** observing an account is not authority to trade it.

These principles guide development; they are not a certification of the experimental implementation.

## Project Status

VidarNet is in an **experimental research and development** phase. Public demonstrations use synthetic test data. Real-account operation, continuous-deployment reliability and autonomous execution have not been validated.

The code is public for inspection, but **no open-source license has been granted**.
